# Quarter Club

A little browser arcade for quick rounds and one-more-try high scores. Pick a cabinet, learn its controls, and play right in your browser.

## The games

**Classics:** Snake, Pong, Frogger, Maze Chase, Dig Dug, Barrel Hop, Paddleball  
**Action:** Breakout, Space Invaders, Centipede, Missile Command, Asteroids, Bomb Squad, Galaga, Downhill, River Raid, Turbo Racer, Space Jump  
**Puzzle:** Lunar Lander, Tile Hopper, Simon, Tetris

## Play

Open `index.html` in a browser, or serve the folder locally:

```sh
python3 -m http.server 8000
```

Then visit [http://localhost:8000](http://localhost:8000).

## Controls

- Use the arrow keys or WASD to move. Controls vary by game.
- Use Space for the game's action, such as firing, jumping, or dropping a bomb.
- On touch screens, use the on-screen controls.
- Press `/` to search the game list and `Esc` to leave a game. Pause and restart are available in the game cabinet.

High scores are saved in your browser on the current device.

## Built with

HTML, CSS, and vanilla JavaScript. No install or build step required.
